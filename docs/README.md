# Project Documentation

This directory contains technical documentation for the shared build and release pipeline.

## Structure

```
docs/
├── README.md          # This file
├── architecture.md    # Release system architecture
├── citations.md       # CSL single-source citation pipeline + witness (tier) contract
├── counts.md          # Generated counts ledger (pnpm run counts; never edited by hand)
├── figures.md         # Deterministic figure pipeline (the five PDFs)
├── installation.md    # Prerequisites and setup
├── style-guide.md     # Family style guide v2.2: editorial (§1–§12), code quality D1–D7 (§13), tex/proofreading (§14)
├── style/             # Portable extracts of the style guide
│   └── grammar.md     # Grammar and usage rules of human language (ES/EN/FR/IT examples)
├── usage.md           # Build, release, commit and version conventions (semver + Zenodo)
├── witness-contract.md   # The single living norm: rationale, standard (§6) and wave-brief shape (§10)
├── witness-decisions.md # The family ledger: one row per question, open and ruled
├── witness-inventory.md # This repository's census of marks, generated from a measurement
├── specs/            # Design specifications (dated, id'd, ISO header)
│   └── 20261116_SPEC-001_deterministic_self_citations.md
└── reports/           # Specific, repository-tied reports (dated, id'd)
    └── README.md      # Reports convention (template) + index of this repository's reports
```

The index of the reports is the table at the end of `reports/README.md`;
it is not enumerated here, because a report is added by that index and not
by this tree.

`docs/` itself stays generic (rules and rationale, portable across the
sibling repositories); anything tied to one repository state — per-site
inventories, decision logs, verdict tables — goes to `docs/reports/`.

## Contents

- **architecture.md**: Tech stack, execution flow, reproducibility measures, scripts structure.
- **citations.md**: How `citation.csl.json` drives the bibliography, CITATION.cff and .zenodo.json; §8 is an index: it points to the family standard in `witness-contract.md` §6 (the quantified inline / line-of-its-own criterion is §6.10) and to this repository's applied state in `reports/`.
- **counts.md**: The measured counts of this repository — suite totals, census size, `\testref{...}` anchors, Lean source statistics, the numbered sections of the package, figure inventory — with the command that measures each and the marked region that quotes it (including the `\Count…` macros the prose of `main.tex` prints). Generated by `pnpm run counts`; `pnpm run counts:check` (inside `validate`) fails when it or a region drifts, and `pnpm run build` re-syncs the regions before the render.
- **figures.md**: What `pnpm run generate:figures` guarantees and why (byte-stable, text-extractable PDFs); the concrete figure-1 incident is [FIG-001](reports/20261116_FIG-001_figure_1_deembed.md).
- **installation.md**: Prerequisites and setup instructions.
- **style-guide.md**: The family style guide (v2.2): editorial rules (§1–§12), including the rigorous IMRAD structure of §7 (section roles, antecedent before use, discourse thread, and the principal author's exclusive decision on moving content between sections), the software-quality doctrine D1–D7 (§13) and the tex/proofreading pipeline with its cited sources (§14). Generic across the family: this repository's own conventions are linked, never copied — the standard and its rationale in `witness-contract.md`, grammar rules in `style/grammar.md`.
- **style/grammar.md**: The grammar and usage rules extracted from `style-guide.md` §1.5 — language-neutral (complete structure, agreement, clear reference, voice, punctuation, economy), worked in Spanish, English, French and Italian, with the RAE-checked Spanish `se` verbs and their sources.
- **usage.md**: Daily workflow, conventional commits, build and release commands.
- **witness-contract.md**: The single living norm of the witness marks — the rationale (§1–§5,
  §7: evidence classes, usability, compactness, the declared novelty), the standard itself
  (§6: precedence, syntax, placement, naming, grammar and the writing rules, the star,
  typography, gates, alphabet, the quantified inline / own-line criterion §6.10, the own-line
  rendering form §6.12, the ledger segmentation §6.13) and the required shape of a wave brief
  (§10). Portable across the family: byte-identical and manifest-pinned.
  **witness-decisions.md** is the decision ledger, one row per question (a count is never a
  row); **witness-inventory.md** is this repository's generated census of marks. The applied
  state of *this* repository — counters, verdicts and the author's pending rows — is
  [WIT-003](reports/20261117_WIT-003_rationale_applied_state.md).
- **specs/**: Design specifications — proposals that change the pipeline or a
  shared artifact, with purpose, evidence, acceptance criteria and open
  questions; first entry
  [SPEC-001](specs/20261116_SPEC-001_deterministic_self_citations.md)
  (deterministic self-citation blocks in the READMEs).
- **reports/**: Specific reports — per-site inventories, decision logs, verdict tables, audits
  and incident records tied to one repository state. The convention (naming, ISO header, index
  format) and the full index of this repository's reports are in `reports/README.md`; they are
  not enumerated here, because that index is what a new report joins.
